# Branding

## Name

The product name is **Kyber Fox**, two words, in the interface and the docs.
Code and file names use `kyberfox`: the binary, the app ID, the profile
directory, pref names (`kyberfox.*`) and the package name. The repository is
`Commanderx-code/KyberFox`.

Open questions about the name are in [licensing.md](licensing.md#name-and-theme-names).

The private logo replaces Firefox's own mask on the private window page, the
private tab and the private window button, through
`patches/kyber/private-browsing-logo.patch`.

On Linux, private windows have their own window class, `kyberfox-private`
(the Wayland app ID and the X11 `WM_CLASS`), set by
`KyberPrivateWindow.sys.mjs` through `patches/kyber/private-window-class.patch`.
The desktop shows them as a separate app in the taskbar with the private logo.
The Arch package installs `kyberfox-private.desktop` (hidden from the app
menu) and the `kyberfox-private` icons for that; the browser ships them as
`chrome/icons/default/kyberfox-private<size>.png`. Without the desktop file
the class is not set, so a plain tarball install keeps one icon for all
windows. `browser.privateWindowSeparation.enabled`, Firefox's switch for the
same thing on the Windows taskbar, turns it off.

To change the logo, replace the files in `branding/` and run
`sh tools/make-logos.sh` from the repository root. Sizes with a render are used
as they are; other sizes are scaled down from the 1254 px original.

## Theme direction

Kyber Fox already ships Ember (dark, the default), Paper (warm light, serif),
Frost, Terminal, Catppuccin Mocha, Tokyo Night and Starry as color themes,
GX-style and One-style as full skins, and the Kyber themes (Kyber Crystal, the
default for new profiles, Crimson and Azure), which also restyle the new tab
and private window pages ([themes.md](themes.md)). All color themes
share one stylesheet driven by CSS variables, so a new palette is a set of
values, not new code.

Planned (see [ROADMAP.md](../ROADMAP.md), Phase 5):

- A neon or cyberpunk palette, with optional glow on focused and active
  elements, off by default.
- Glass, an original remake (no code from Glass-Firefox-Theme or LIQUID-GLASS,
  which have no license).

Rules for every theme: body text and controls must stay readable (aim for
WCAG AA contrast), focus rings must stay visible for keyboard users, and glow
or animation must respect reduced-motion settings.

## What Kyber Fox must not use

- Firefox or Mozilla names and logos as branding. "Based on Firefox" style
  wording is discussed in [licensing.md](licensing.md).
- Brave's lion, Opera's "O", or any other browser's logo or name.
- Images or code from projects without a license.
