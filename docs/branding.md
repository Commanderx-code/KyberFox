# Branding

## Name

The product name is **Kyber Fox**, two words, in the interface and the docs.
Code and file names use `kyberfox`: the binary, the app ID, the profile
directory, pref names (`kyberfox.*`) and the package name. The repository is
`Commanderx-code/KyberFox`.

Open questions about the name are in [licensing.md](licensing.md#name-and-theme-names).

## Theme direction

Kyber Fox already ships Ember (dark, the default), Paper (warm light, serif),
Frost, Terminal, Catppuccin Mocha, Tokyo Night and Starry as color themes, and
GX-style and One-style as full skins ([themes.md](themes.md)). All color themes
share one stylesheet driven by CSS variables, so a new palette is a set of
values, not new code.

Planned (see [ROADMAP.md](../ROADMAP.md), Phase 5):

- A neon or cyberpunk palette, with optional glow on focused and active
  elements, off by default.
- A palette from the owner's Jedi-inspired mockups. Its name must not use
  "Jedi" or other Star Wars terms until the trademark question is answered.
- Glass, an original remake (no code from Glass-Firefox-Theme or LIQUID-GLASS,
  which have no license).

Rules for every theme: body text and controls must stay readable (aim for
WCAG AA contrast), focus rings must stay visible for keyboard users, and glow
or animation must respect reduced-motion settings.

## What Kyber Fox must not use

- Firefox or Mozilla names and logos as branding. "Based on Firefox" style
  wording is discussed in [licensing.md](licensing.md).
- Brave's lion, Opera's "O", or any other browser's logo or name.
- Images or code from projects without a license.
