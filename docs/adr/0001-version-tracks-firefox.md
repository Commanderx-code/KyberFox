# Kyber Fox versions track the Firefox release

A Kyber Fox version is the Firefox release it is built from plus a build counter, such as `159.0-1`, in the style of LibreWolf. An independent product version like `1.0` was considered and rejected: it hides which Firefox security fixes an install carries, and for a fork whose main duty is shipping those fixes within 72 hours, that number is the one users and the owner need to read at a glance.
